#  Intelligent Infrastructure Management System based on AI Agent Architecture and Model Context Protocol (MCP)
# Hệ Thống Quản Trị Hạ Tầng Thông Minh dựa trên Kiến trúc AI Agent kết hợp MCP Server

## Giới Thiệu Đề Tài

Dự án này là nội dung báo cáo **Đồ án chuyên ngành** thuộc ngành Mạng máy tính và truyền thông dữ liệu tại **Trường Đại học Công nghệ Thông tin (UIT)**

Đề tài tập trung vào việc đề xuất và phát triển một hệ thống quản trị hạ tầng thông minh dựa trên kiến trúc **AI Agent** kết hợp giao thức **Model Context Protocol (MCP)**. Hệ thống cho phép quản trị viên tương tác và điều khiển hạ tầng bằng ngôn ngữ tự nhiên thông qua AI, tự động hóa vòng đời cấp phát các tài nguyên cốt lõi trên **AWS**, đồng thời tích hợp cơ chế tự động tóm tắt log và phân tích nguyên nhân khi xảy ra lỗi ở bước thực thi.
